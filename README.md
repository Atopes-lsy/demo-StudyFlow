# StudyFlow - HarmonyOS 校园学习任务管理应用

StudyFlow 是一个基于 HarmonyOS 的校园学习任务管理应用，面向学生日常学习场景，提供任务管理、学习记录、资料推荐和个人中心等功能。项目使用 ArkTS 与 ArkUI 开发，重点体现组件化页面设计、状态管理、本地存储、网络通信和完整开发流程。

## 项目背景

在课程学习、作业安排和考试复习过程中，学生经常需要同时管理多门课程、多个截止时间和阶段性学习计划。本项目希望通过移动端应用帮助用户记录学习任务、查看完成进度、进行学习打卡，并通过推荐页获取学习资料或公告内容。

## 核心功能

- 首页仪表盘：展示今日任务、完成进度、学习时长和快捷入口。
- 任务管理：支持新增、编辑、删除、完成任务和任务筛选。
- 学习记录：支持学习打卡、记录学习时长、查看历史记录。
- 资料推荐：通过模拟网络请求展示学习资料、课程公告或推荐内容。
- 个人中心：展示用户信息、应用设置、数据清理等内容。

## 技术要点

- ArkTS：实现页面逻辑、数据模型和状态处理。
- ArkUI：实现应用页面、组件布局和交互效果。
- 状态管理：维护任务列表、完成状态、学习记录等页面状态。
- 本地存储：保存任务数据和学习记录，支持应用重启后恢复。
- 网络通信：使用模拟接口或远程 JSON 获取推荐内容。
- GitHub 协作：通过分支、Issue、Pull Request 管理小组开发流程。

## 小组分工

| 成员 | 角色 | 主要职责 |
| --- | --- | --- |
| 组长 | 项目统筹与核心模块 | GitHub 仓库管理、需求分析、整体页面流程、首页仪表盘、数据结构设计、报告整合和答辩总述 |
| 组员 1 | 任务管理模块 | 任务列表、新增任务、编辑任务、删除任务、完成状态切换、任务筛选和模块测试 |
| 组员 2 | 学习记录与扩展模块 | 学习打卡、历史记录、资料推荐、个人中心、网络请求、测试截图整理 |

## 分支规范

- `main`：最终稳定版本，只存放可提交、可演示的代码。
- `dev`：日常集成分支，功能完成后先合并到这里。
- `feature/home`：首页、数据模型和基础框架。
- `feature/task`：任务管理模块。
- `feature/record`：学习记录、资料推荐和个人中心模块。
