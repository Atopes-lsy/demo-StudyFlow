# 三人分工

> 版本：2.0 | 日期：2026-10-10 | 产品方向：课表日程提醒助手

## 1. 分工原则

组长负责共享契约、服务层搭建和核心架构；组员 1 负责登录注册、课表、日程、首页的业务完善和测试；组员 2 负责通知提醒、API 配置、角色设定、智能提醒的业务完善和测试。前端后续用 Figma 替换，当前代码仅保证功能跑通。

## 2. 职责与交付

| 成员 | 负责模块 | 具体交付 |
| --- | --- | --- |
| 组长 | 契约、服务层、架构 | 全局类型、Preferences/Auth/Data/Notification/Http/SmartReminder 服务、配置文件、PRD、文档更新 |
| 组员 1 | 登录注册 + 课表 + 日程 + 首页 | 验证和完善登录注册流程、课表增删改查、日程增删改查、首页仪表盘、业务测试和截图 |
| 组员 2 | 通知 + 提醒设置 + API + 角色 + 智能提醒 | 定时提醒实现、提醒设置完善、API 配置验证、角色设定完善、智能提醒验证、安全测试和截图 |

### 组长的边界

- 核心代码为共享类型和服务层搭建，不包办页面 UI 细节。
- 不建立后端服务器，不永久保存 API Key。
- 负责 PR 评审、报告整合和答辩总述。

### 组员 1 的边界

- 在组长搭建的基础上完善登录注册、课表、日程、首页功能。
- 补充课程编辑、学期设置、日程编辑、筛选等缺失功能。
- 负责业务测试、截图和数据恢复验证。

### 组员 2 的边界

- 在组长搭建的基础上完善通知提醒、API 配置、角色设定、智能提醒功能。
- 实现定时提醒（每日/课前/日程），当前仅有手动触发。
- 负责安全验证（Key 不落盘/不进日志）、通知测试和截图。
