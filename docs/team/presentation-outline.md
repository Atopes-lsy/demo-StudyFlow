# 答辩与报告安排

> 版本：2.0 | 日期：2026-10-10 | 产品方向：课表日程提醒助手

## 1. 时间安排

| 顺序 | 人员 | 内容 | 时间 |
| --- | --- | --- | --- |
| 1 | 组长 | 产品定位、架构、核心功能总述 | 1-1.5 分钟 |
| 2 | 组员 1 | 登录注册、课表、日程、首页演示 | 2 分钟 |
| 3 | 组员 2 | 通知提醒、API 配置、角色设定、智能提醒演示 | 2 分钟 |
| 4 | 组长 | 测试、安全、总结 | 1-1.5 分钟 |

总计约 6-7 分钟。

## 2. 演示脚本

1. 组员 1 展示注册→登录→添加课程→添加日程→首页概览。
2. 组员 2 展示提醒设置→授权通知→发送测试提醒。
3. 组员 2 展示 API 配置→添加角色→开启智能提醒→发送角色语气提醒。
4. 组长演示 API 失败回退基础文案、Key 不落盘验证。

真实 API Key 不出现在截图、日志或讲稿。

## 3. 技术说明

- 组长：契约设计、服务层架构、数据隔离、安全边界。
- 组员 1：登录注册、课表/日程 CRUD、首页聚合、本地恢复。
- 组员 2：通知机制、API 适配、角色 prompt、智能提醒降级策略。
- 共同：Issue、PR、联调与测试证据。
