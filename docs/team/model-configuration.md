# 用户自带 API Key 与模型配置

## 1. 范围与状态

待实现功能：体验者使用自己的模型服务账号生成学习计划。首期验证一个服务预设及同 Chat Completions 格式、Bearer 鉴权的 HTTPS 兼容服务，不承诺所有模型、工具、流式输出、图片或语音都支持。

推荐端侧直连模型，不由小组服务器接收 Key。模型选择、预算和真实付费测试尚待确认，不提供公共密钥。

## 2. 页面与流程

入口：AI 规划页的“模型设置”以及设置入口。

| 控件 | 行为 |
| --- | --- |
| 服务选择 | 选择已验证预设或自定义兼容服务 |
| Base URL | 预设默认锁定，自定义填写 API 基础地址而非完整生成接口 |
| 模型 ID | 有列表时选择，不支持列表时手动填写 |
| API Key | 默认遮蔽，眼睛图标切换显示，回到前台后重新遮蔽 |
| 检查连接 | 主动检查，不自动生成学习计划 |
| 验证生成 | 确认可能产生费用后，进行一次限长生成测试 |
| 应用配置 | 非密钥配置落盘，Key 仅保留在当前进程 |
| 清除 Key | 清除凭据、输入与关联请求，不删除学习任务 |

状态区分未配置、已配置、鉴权通过、生成已验证。模型列表成功不代表指定模型能生成；不支持列表也不等于 Key 无效。Key 不强制使用某个前缀。

配置后用户输入目标和每日预算，查看并确认必要任务摘要发往哪个服务；生成草稿经过校验、编辑、再次校验和确认后才保存。

## 3. 密钥与地址边界

- Key 独立于普通配置，只进入用户确认的模型服务鉴权头；不进入 URL、提示词、工具参数、日志、任务、截图或导出。
- 首期不永久保存 Key。进程结束后重新输入；移除引用不等于能保证擦除运行时全部字符串副本，也不保证终端密钥绝对不可提取。
- 结构化解析 URL；只允许 HTTPS，拒绝用户名密码、查询参数、片段及完整生成路径误填。
- 显示实际目标主机，自定义服务须确认凭据将交给该地址。地址或服务变化后清除旧 Key 与验证状态，不自动复用凭据。
- 正常校验证书，不允许忽略 TLS 错误，不自动跟随重定向。
- 远端错误可能回显敏感内容，先脱敏再显示或记录；日志只保留必要标识、状态、耗时及实际返回用量。
- 任务默认本地保存，但授权摘要会由外部模型服务处理；不得承诺“所有数据永不出设备”。
- 后续“记住 Key”须先验证目标 SDK 和设备的安全资产存储能力，不以普通明文配置或硬编码加密密钥替代。

## 4. 请求与费用

- 首期非流式，最多一个在途生成请求；按钮和请求层均防重复触发。
- 鉴权、额度、限流、超时、模型不存在和格式错误按服务实际响应映射，默认零自动重试。
- 用户主动确认真实生成，限制输入与输出规模；Token 限制不是费用硬上限，不编造价格。
- 取消只能中止客户端等待或请求，不能保证模型服务停止计费。
- 取消、超时、换配置或清除 Key 后，旧请求响应不得更新当前草稿或写入任务。
- 解析或校验失败时保留编辑/手动重试入口，不自动付费修复。

## 5. MCP 边界

MCP 为可选工具协议连接，不是模型接口别名。基础版通过后，先验证端侧 Client 和最多两个只读工具；不假定存在开箱即用的 ArkTS SDK。

模型 Key 不作为 MCP 认证，不进入工具参数或结果。MCP 凭据与授权独立；未完成真实协议发现、调用与测试，不宣称接入。

## 6. 分工与验证

组员 2 实现配置、会话凭据、模型适配、请求控制、AI 页面与网络测试；组员 1 实现上下文摘要及确认保存；组长定义契约和计划校验，评审关键边界。详见[分工](task-division.md)。

先使用假 Key 与测试替身，验证地址、凭据、失败、取消和零自动重试。确认服务和预算后，由用户主动触发一次真实联通；不自动向真实服务发测试请求。用例见[测试报告](test-report.md)。
